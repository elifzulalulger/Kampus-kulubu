# Kampüs Kulübü

Kampüs Kulübü, üniversite öğrencilerinin kampüs etkinliklerini keşfetmesi için hazırlanmış bir web sitesidir.

## Proje Özellikleri

- Ana sayfa
- Etkinlikler sayfası
- Hakkımızda sayfası
- Etkinlik arama özelliği
- Arama sonuçlarını temizleme
- Mobil uyumlu tasarım

## Kullanılan Teknolojiler

- HTML
- CSS
- JavaScript

## Nasıl Kullanılır?

1. Projeyi GitHub üzerinden açın.
2. index.html dosyasını tarayıcıda görüntüleyin.
3. Etkinlikler sayfasından etkinlik araması yapın.
